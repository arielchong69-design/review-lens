# 测试说明

## 运行方式

```bash
npm test                                          # 单元测试（Node 18+，无依赖）
node scripts/dev-server.mjs --mock &              # 本地服务（合成数据，无需 Key）
BASE=http://localhost:8788 node scripts/e2e.mjs   # 端到端测试（Playwright + Chromium）
```

当前结果：单元测试 **45 项全部通过**；端到端 **9 个步骤全部通过**（唯一的控制台 404 是本地没有放离线快照文件，属预期）。
