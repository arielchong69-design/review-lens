# 测试说明

## 运行方式

```bash
npm test                                          # 单元测试（Node 18+，无依赖）
node scripts/dev-server.mjs --mock &              # 本地服务（合成数据，无需 Key）
BASE=http://localhost:8788 node scripts/e2e.mjs   # 端到端测试（Playwright + Chromium）
```

当前结果：单元测试 **78 项全部通过**（原有 53 项 + 证据相关性新增 25 项）；端到端 **9 个步骤全部通过**（唯一的控制台 404 是本地没有放离线快照文件，属预期）。

## 四、证据相关性校验（tests/relevance.test.mjs）

| 编号 | 场景 | 预期 | 结果 |
|---|---|---|---|
| V1 | 证据类型与时序按 ID 结构确定；新增计划/规则证据带可核对字段 | 退出计划记录为 missing、追涨规则为 triggered、当日涨跌为“当日部分可知”、成交价为“决策时点已知” | 通过 |
| V2 | **真实但不相关的证据**：“退出计划未填写”引用成交价 | 不相关引用移除，结论降为“证据有限”，事实改为推断并加“（证据有限）” | 通过 |
| V3 | 同一结论附带结构化断言 | 对照交易记录核对通过，自动关联真实的记录证据，成交价仍被移除 | 通过 |
| V4 | **主题误标**：讲退出计划却标“走势”、引用涨跌幅（类型匹配） | 数值锚定失败 → 证据有限，提示“可能是主题标注有误” | 通过 |
| V5 | 主题误标对照组：主题与数值都正确 | 结构化校验通过 | 通过 |
| V6 | 断言优先于主题：断言与交易记录 / 规则结果矛盾 | 隐藏，并说明与记录不符 | 通过 |
| V7 | **事后证据误用**①：事前结论引用决策后证据 | 整条移除 | 通过 |

| V14 | **部分支撑**：“相对基准”缺少基准证据 | 证据有限 | 通过 |

## 五、真实数据验证
